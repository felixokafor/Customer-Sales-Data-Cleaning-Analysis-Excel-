# Customer-Sales-Data-Cleaning-Analysis-Excel-
This project focuses on cleaning and transforming a raw customer sales dataset into a structured format suitable for analysis.
The dataset contained multiple inconsistencies such as missing values, duplicate records, and formatting issues, which were resolved using Excel data cleaning techniques.
🛠️ Tools Used
• Microsoft Excel
• Pivot Tables
• Data Cleaning Functions (TRIM, PROPER, IF, AVERAGE)
🔧 Data Cleaning Process
• Removed duplicate records
• Standardized text fields (names, regions)
• Handled missing values in key columns
• Converted inconsistent date formats
• Validated email entries
• Cleaned phone number formats
  Analysis Performed
• Total Revenue Calculation
• Revenue by Region
• Top Customers by Revenue
  Key Insights
• Data inconsistencies significantly impacted initial analysis
• Revenue contribution is concentrated among a few customers
• Clean data enabled accurate aggregation and reporting
  Future Improvements
• Automate cleaning using Power Query
• Build interactive dashboards
• Expand dataset for deeper analysis
